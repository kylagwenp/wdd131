Information about the words, artwork, and tools used in this class project.

Painting content

The six lessons were drafted for this project. The illustrations are digital practice examples that accompany the lessons, rather than photographs of physical paintings.

Artwork and design

The palette logo, wireframes, and painting illustrations were created as SVG artwork for this project. The painting illustrations were exported to optimized WebP files. No stock photographs or third-party website templates were used.

The site uses Georgia and Arial system fonts with standard serif and sans-serif fallbacks.

Project resources

  • BYU–Idaho WDD 131: Final Website Project requirements — project specifications.
  • MDN: Window.localStorage — browser storage reference.
  • MDN: Client-side form validation — HTML form validation reference.

About the form

The tutorial request form is a browser demonstration. It stores only a submission count, does not retain names, email addresses, or messages, and does not deliver requests to a server. Saved painting IDs are stored separately on the same browser.
